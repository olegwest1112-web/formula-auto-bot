# Formula Auto

Telegram Mini App автосалону Formula, Нововолинськ. Каталог, заявки менеджеру та панель команди.

- [Каталог](https://olegwest1112-web.github.io/formula-auto-bot/)
- [Вхід команди через бота](https://t.me/formulatestastrabot?start=admin)
- [Панель у браузері](https://formula-auto-nv-mini.olegwest1112.chatgpt.site/admin)
- [Інструкція компанії](COMPANY-HANDOVER.md)

## Можливості

Каталог: пошук, фільтри, сортування, галереї, обране, порівняння до трьох авто, запити на перегляд, обмін, підбір і фінансування. Дані читаються із сервера; при помилці застаріла локальна база не підставляється.

Автомобілі: короткі чернетки, перевірка перед публікацією, до 24 JPG/PNG/WebP по 8 МБ, обкладинка й порядок фото, приховування, бронювання, продаж, архів і відновлення. VIN і посилання на оголошення захищені від дублювання. Одночасне редагування перевіряє версію запису; повторне створення — ключ операції.

Заявки: пошук і сторінки, статуси від нової до продажу або відмови, відповідальний менеджер, нотатки, дата наступного контакту та повторне сповіщення Telegram. Заявка зберігається навіть при недоступності Telegram. Експорт автомобілів і заявок доступний власнику. Історія змін має сторінки та автора дії.

Команда: власник, менеджер заявок, редактор каталогу. Запит на доступ створюється після першого входу працівника через бота. Права перевіряються сервером у кожному запиті. Зміна ролі завершує сеанси працівника. Останнього активного власника не можна прибрати.

## Дані та бренд

Логотип і фотографії — з [каналу Formula](https://t.me/formula_auto_nv). Підготовлено добірку 16 оголошень дилера у backend/source-catalog.json; приватні оголошення сторонніх власників відсіяно. Це знімок джерела, а не автоматична перевірка наявності. Раніше додані картки імпорт не перезаписує. Проданий Renault Zoe має статус «Продано», пробіг Velar — у милях. Реальну наявність і ціну підтверджує менеджер. Ставки, гарантії й відгуки не вигадані.

## Архітектура

dist/ — статичний клієнт GitHub Pages. backend/ — Cloudflare-сумісний ESM Worker, D1 та R2 через Sites. admin/ — панель на домені сервера. GitHub Actions перевіряє код, публікує клієнт і оновлює існуючий пост тестового каналу. Сервер публікується через Sites окремо; одного push у GitHub для нього недостатньо. Репозиторій містить код обох частин.

Telegram-вхід перевіряє підпис initData, термін п'ять хвилин, повторне використання та незмінний числовий ID. Сеанс діє вісім годин; у базі зберігається хеш, у браузері — HttpOnly cookie та запасний токен лише в пам'яті для Telegram Web. Вхід через особистий ChatGPT тимчасово збережено для передачі; власник Telegram може вимкнути його у «Команда».

### Середовище

GitHub Actions: секрет TELEGRAM_BOT_TOKEN, змінна TELEGRAM_POST_ID для оновлення існуючого поста.

Sites: TELEGRAM_OWNER_ID — підтверджений числовий ID першого власника; ADMIN_EMAILS — резервний доступ до завершення передачі. Секрети: TELEGRAM_BOT_TOKEN, MANAGER_CHAT_ID, RATE_LIMIT_SALT, WEBHOOK_SECRET. Значення задаються в середовищі Sites, не в репозиторії. Webhook: /api/telegram/webhook, із секретним заголовком Telegram. Зміна контактного @username у панелі не змінює серверний chat ID отримувача заявок.

### Розробка

Node.js 24: npm ci, npm test, npm run check, npm run build. Команда npm run db:generate генерує міграції зі db/schema.ts; застосовані міграції не редагувати. Збірка сервера — build/server/index.js і build/.openai/; для Sites каталог пакується як dist/ архіву. Публічний dist/ GitHub залишається окремим.

Тести перевіряють Telegram-підпис, права, відкликання доступу, останнього власника, передачу керування, чернетки, публікацію, архів, конфлікти змін, дублікати, заявки, обмеження частоти, CORS і доступ до фото. Тестовий режим реально зберігає заявки й надсилає їх тестовому менеджеру.
