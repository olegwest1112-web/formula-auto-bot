# Formula Telegram Mini App

## Тестовый запуск через GitHub

Тестовый бот: `@formulatestastrabot`. Тестовый канал: `@formulatestttt`.
`dist/config.js` включает тестовый режим: форма не отправляет заявки реальному менеджеру и не сохраняет персональные данные.

1. Загрузите проект в `olegwest1112-web/formula-auto-bot`, ветка `main`.
2. В Settings → Pages выберите Source → GitHub Actions. Для приватного репозитория может потребоваться платный план GitHub; не меняйте видимость репозитория без решения владельца.
3. В Settings → Secrets and variables → Actions добавьте секрет `TELEGRAM_BOT_TOKEN`. Никогда не записывайте его в код или workflow.
4. В Actions запустите `Deploy Formula Mini App`. Для первого поста включите `publish_channel_post`.
5. Сохраните полученный номер поста из отчёта запуска в переменную репозитория `TELEGRAM_POST_ID`. Последующие запуски будут редактировать этот пост. Без переменной новые посты создаются только по ручному флагу.

GitHub публикует `dist` на Pages, затем настраивает кнопку меню бота и пост в тестовом канале. В канале используется обычная ссылка на бота: Telegram разрешает `web_app`-кнопку только в личном чате с ботом. Откройте бота, нажмите «Почати», затем «Каталог авто» возле поля сообщения.

Это статическая Mini App. У бота нет постоянного обработчика сообщений `/start`: каталог открывается через настроенную кнопку меню. Автоматическая обработка заявок потребует отдельного серверного приложения.

Мобильный каталог автосалона Formula. Статическое приложение без зависимостей: содержимое `dist` можно разместить на любом HTTPS-хостинге.

## Возможности

Каталог, поиск по модели, фильтр наличия, сортировка, локальное избранное, фотогалерея, исходные объявления, контакты. Форма подготавливает сообщение в Telegram менеджеру `@l_e_v_a_nv`; посетитель вручную подтверждает отправку. Сервер не получает и не хранит заявки. Никакие сообщения автоматически не отправляются.

## Подключение к Telegram

1. Разместите содержимое `dist` на публичном HTTPS-хостинге. Закрытый Sites-предпросмотр предназначен владельцу, не клиентам.
2. В @BotFather выберите нужного бота: /mybots → Bot Settings → Configure Mini App. Укажите публичный адрес приложения. Можно также настроить Menu Button через BotFather.
3. Откройте приложение из профиля бота на телефоне. Проверьте карточку авто и подготовку заявки. Для проверки не отправляйте тестовые данные менеджеру без согласования.

Токен бота не нужен для текущего интерфейса, не добавляйте его в браузерные файлы. Для автоматической обработки заявок понадобится отдельный сервер с проверкой Telegram initData, защитой от спама и секретами в окружении.

Официальная документация: https://core.telegram.org/bots/webapps
